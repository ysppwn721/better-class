# 课表 · 一张截图生成可视化课表

> 给「教务系统截图长得像 Excel、手机上根本看不清」这件事做的工具。
> 一张截图（或一段复制文本）→ 生成 WakeUp 风格的 7×N 可视化课表，支持**夏季/冬季两套作息**。

面向**任何高校**（不是只服务某一个学校）：识别是通用的，作息时间表可切换预设或自行编辑。
内置了中北大学（NUC）的冬/夏作息预设，开箱即用。

**三种用法**：网页 / 单文件离线版 / Android APK —— 详见下方「安装」。

---

## 30 秒上手

```bash
# 方式一：直接打开单文件版（最省事）
apk/www/index.html        # 双击即可，不需要服务器、不需要联网

# 方式二：开发模式（改代码即时生效）
node server.mjs 5173
# 浏览器打开 http://127.0.0.1:5173

# 方式三：出 APK 装手机
node tools/build_apk.mjs  # → out/kebiao-debug.apk
```

首次打开是空课表，点底部**导入课表**，两条路都行：

| 通道 | 成本 | 准确率 | 适用 |
|---|---|---|---|
| **粘贴文本** | 0 | 100%（规则解析） | 教务系统能复制文本时首选 |
| **截图识别** | 需要视觉模型 | 高，可复核 | 只有截图（如企业微信转发）时 |

也可以点空状态里的**载入示例**先看效果。

## 功能

**课表显示**
- 7 天 × 大节网格；课程跨相邻大节自动连成整块
- 左侧时间轴显示「大节序号 + 起止时间」；表头显示星期与日期，**今天高亮**
- 当前周的今天会画一条**红色当前时间线**
- 每门课一个配色（同一课名固定同色，最多 10 色循环）
- 卡片显示：课名 / 地点 / 教师（信息不够时不硬塞，点开看详情）

**周次与作息**
- 周次 1–N 任选，支持 `1-12周`、`1-8,10-16周`、`单周`、`双周`、每周
- **不匹配当前周次的课自动隐藏**（并提示"本周另有 N 门课不上"）
- 夏季作息 / 冬季作息一键切换；默认按日期自动切换
  （中北大学：五一后～国庆前 = 夏季，其余 = 冬季）
- 作息时间表可在「设置」里逐条编辑；也内置了「通用 45 分钟/节」预设

**导入 / 导出**
- 导入：截图识别（多通道）· 粘贴教务系统文本 · 粘贴 HTML 表格 · 逐条手输
- 识别结果可逐条**复核**（缺星期/节次/周数的会打 `?` 标记）
- 导出：JSON（备份/分享）· 当前周 PNG 图片 · ICS 日历（每节课提前 15 分钟提醒）· 可粘贴文本

**其它**
- 深色模式（跟随系统 / 手动切换）
- 数据全部存在本机 `localStorage`，不上传
- 手机竖屏优先；360 / 390 / 420 / 768 宽度都做了适配（自动缩放列宽保证 7 天全在屏内）

## 安装

| 方式 | 怎么做 | 说明 |
|---|---|---|
| **网页** | 打开 `apk/www/index.html` | 零依赖、可离线 |
| **添加到主屏幕** | 手机浏览器打开单文件 → 菜单「添加到主屏幕」 | 免安装，像 App 一样用 |
| **APK** | `node tools/build_apk.mjs` → `out/kebiao-debug.apk` | 约 60 KB，Android 7+ |

APK 的 CI：推上 GitHub 后，`.github/workflows/android.yml` 会自动构建并上传
Artifact；打 `v*` 标签则自动发 Release。
详见 [`docs/打包APK.md`](docs/打包APK.md)。

## 让用户「零配置」用上 AI 识别

Key 不能放进客户端。做法是在服务端放一层代理（`server/index.mjs`，零依赖）：

```
APK / 网页 ──图片──► 你的代理（持 Key）──► 智谱 / 硅基流动 / OpenRouter
```

```bash
# 1) 部署代理（Cloudflare Workers / Deno / VPS 都行）
# 2) 构建时把地址内嵌进去
BC_AI_ENDPOINT=https://你的地址 node tools/build_apk.mjs
```

这样用户装上 App 直接就能识别，什么都不用填。
完整步骤（含免费额度申请、防盗刷、限流）见 [`docs/AI通道部署.md`](docs/AI通道部署.md)。

> 不部署也完全可用：「粘贴文本」通道零成本、零依赖，而且比 AI 更准。

## 数据格式（v1）

`src/demo-data.js` 就是格式样例，照着改即可手工维护：

```js
{
  settings: {
    title: '我的课表',
    semesterStart: '2026-08-31',   // 第 1 周周一
    totalWeeks: 19,
    preset: 'nuc',                 // 作息预设
  },
  schedule: {
    winter: { label: '冬季作息', units: [
      { periods: '第1-2节', start: '08:00', end: '09:40' },   // units[0] = 第 1 大节
      // …
    ]},
    summer: { /* 同上 */ },
  },
  courses: [
    {
      name: '数据结构', teacher: '张钰嘉', location: '15207Z', campus: '本部',
      day: 4,            // 1=周一 … 7=周日
      startUnit: 3,      // 第 3 大节 = 第5-6节
      endUnit: 3,        // 与 startUnit 不同表示连堂（会画成一整块）
      weeks: '2-16周',   // 支持 "1-8周,10-16周" / "单周" / 空 = 每周
      credit: '4',
    },
  ],
}
```

关键约定：**「大节」是网格行**。第 1 大节 = 第 1-2 小节，第 2 大节 = 第 3-4 小节，依此类推。
教务系统里看到的「3-4」就是第 2 大节。

## 作息时间（中北大学）

中北大学分冬/夏两套（来源：中北大学机械工程学院《关于执行冬季作息时间的通知》，
"国庆休假结束之后执行冬令作息"，五一后转夏令）：

| 大节 | 冬季作息 | 夏季作息 |
|---|---|---|
| 第一大节（第1-2节） | 08:00–09:40 | 08:00–09:40 |
| 第二大节（第3-4节） | 10:10–11:50 | 10:10–11:50 |
| 第三大节（第5-6节） | 14:00–15:40 | 14:30–16:10 |
| 第四大节（第7-8节） | 16:10–17:50 | 16:40–18:20 |
| 第五大节（第9-10节） | 19:00–20:40 | 19:30–21:10 |

> 说明：每个大节含 2 小节（各 50 分钟，课间 10 分钟）。
> 这是按学校"大节起止 + 校内通行的小节划分"推定的；如果你的课表实际时间不同，
> 在「设置 → 作息时间表」里改数字即可，不用改代码。

## 截图识别是怎么工作的

`src/extractor.js` 把识别做成**可插拔链路**，从"零配置"到"自备 Key"依次尝试：

1. **本机视觉服务**（无需 Key）— 打到 `POST /vision/extract-schedule`，
   由 DSH 侧的 better-class 插件承接；`server.mjs` 已内置到该路由的代理。
2. **智谱 GLM-4V-Flash**（免费额度）— 在「设置」里选通道并填 Key。
3. **硅基流动 Qwen2.5-VL**（免费额度）— 同上。
4. **任意 OpenAI 兼容端点** — OpenRouter / 阿里百炼 DashScope / 自建，填 URL + Key + 模型名。

识别前图片会等比压到长边 1600px 再发（省 token、降失败率）；
返回的 JSON 会被容错解析（去 markdown 围栏、补尾逗号、中文引号），
识别不出的字段不会瞎编，而是标记 `needsReview` 让用户在界面上确认。

**没配任何 Key 也能用**：走「粘贴文本」通道，规则解析是确定性的，不依赖任何模型。

## 已知限制

- **截图识别依赖视觉模型**。没配通道时该入口会报错并引导改用粘贴文本；这是设计如此，不是故障。
- 教务系统导出的纯文本里，某些排布下「星期/节次」列可能被列宽劈开，
  解析器已处理常见碎片（`班：`、`成：`、`教学` 换行等），但极端排版仍可能缺字段 → 用复核清单补。
- 单文件版在 `file://` 下 `localStorage` 可用、`fetch` 类功能（识别）受限；
  套壳成 APK 后（`http://localhost`）没有这个限制。
- 作息时间与校历是推定值，**请自行核对一次**（设置里可改）。
